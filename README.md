## Sobre o Projeto

Este projeto tem como objetivo realizar a avaliação de qualidade de software do produto open-source [Excalidraw](https://excalidraw.com/), com base nas normas da família **ISO/IEC 25000 (SQuaRE)**, com foco nas seguintes características:

1. **Manutenibilidade**
2. **Confiabilidade**
3. **Portabilidade**

### Motivações

- Contribuição para projeto opensource;
- Possibilidade de avaliação interna do código;
- Prática dos conceitos e normas de qualidade de software aprendidos na disciplina.

---

## Fases da Avaliação

O projeto está dividido em 4 fases:

- **Fase 01 — Estabelecer requisitos de avaliação:** propósito, tipo de produto (caracterização do escopo), partes interessadas e modelo de qualidade (características e subcaracterísticas).
- **Fase 02 — Especificar a avaliação:** definir as métricas (SQuaRE / ISO/IEC 25023) e os critérios de julgamento.
- **Fase 03 — Projetar a avaliação:** definir o método de avaliação, instruções para o avaliador, recursos e cronograma.
- **Fase 04 — Executar a avaliação:** obter medidas, comparar com critérios, julgar os resultados e propor oportunidades de melhoria.

## Como Executar Localmente

O ambiente de documentação foi desenvolvido utilizando **Docusaurus 3**.

### Pré-requisitos

- **Node.js** >= 20.0
- **npm** (ou gerenciador de pacotes equivalente)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/FCTE-Qualidade-de-Software-1/2026-2_T02_KAREN_JONES.git
cd 2026-2_T02_KAREN_JONES

# Instale as dependências
npm install
```

### Desenvolvimento Local

```bash
npm start
```

O site abrirá em `http://localhost:3000/2026-2_T02_KAREN_JONES/`.

### Build de Produção

```bash
npm run build
```

Os arquivos estáticos serão gerados na pasta `build/`.
